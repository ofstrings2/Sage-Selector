# Sage Selector

Source recovery for the TotK 1.2.1 Sage Selector mod, GameBanana submission
[726955](https://gamebanana.com/mods/726955), maintained by
[ofstrings2](https://github.com/ofstrings2).

The final D28 mod provides a radial selector for five Sages, Horse, Memory and
Sleep. This repository preserves the recovered editable modifications and the
published EmoteWheel framework source, with authors and licenses attached.

**Binary release is on hold.** The inherited GPLv2-only/GPLv3 combination and the
exact corresponding-source gaps are documented in [RELEASE_BLOCKERS.md](RELEASE_BLOCKERS.md).
Publishing source and credits does not by itself resolve them.

Read [CREDITS.md](CREDITS.md), [SOURCE_STATUS.md](SOURCE_STATUS.md),
[BUILDING.md](BUILDING.md), [LICENSE_SCOPE.md](LICENSE_SCOPE.md), and
[THIRD_PARTY_NOTICES.txt](THIRD_PARTY_NOTICES.txt).

No Nintendo game executables, game textures, animations, music, donor executables
or playable release binaries are included in this source repository.
